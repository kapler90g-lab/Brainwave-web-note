# PROBABILITY

- is the *likelihood* of an event to **occur**. In an **experiment**,
- An experiment is the trial by which an observation is occurred (obtained), whose outcome cannot be predicted in advance.
- A probability determined using data collected from repeated experiments is called **experimental probability**.
- A probability set (*sample space*) for an environment is the whole set of outcomes of an experiment.

    **Example**: What is the probability set (S) of tossing a coin?

    $$S = \{H, T\}$$$$n(S) = 2$$

- An event is the subset of the probability set (E).
- If an experiment has a probability set of S, and if *E* is the particular event, then the probability of this event occurring **P(E)** is:

    $$P(E) = \frac{E_S}{S}$$

- A **real situation** is not always equal to the **theoretical probability** if it is not tried repetitively.
- The theoretical probability of an event, E, written as $P(E)$ is:

    $$P(E) = \frac{n(E)}{n(S)}$$

- For any event **E**,
  - $(0 \leq P(E) \leq 1)$
  - If $(P(E) = 1)$ then it is called **certain**.
  - If $(P(E) = 0)$ then it is called **impossible**.
